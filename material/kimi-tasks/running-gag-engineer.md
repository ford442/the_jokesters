# Task 3 – Running Gag Engineer

## Prompt

```
You are Kimi Running Gag Creator. Invent 15 evolving running gags themed around gold/crypto that can last across multiple episodes. 

Examples: 
- Chad's ever-changing "all-in" strategy
- Unit-734's portfolio error beeps getting worse
- Philosopher's "what even is money" spiral

Give each gag a name, trigger condition, and 3 escalation levels.
```

## Output Format

```markdown
## Running Gag #1: Chad's Diamond Hands Evolution

**Trigger**: Any mention of holding through a dip

**Escalation Levels**:
1. **Level 1**: "I'm not selling, bro. Diamond hands."
2. **Level 2**: "My hands aren't just diamond, they're boron nitride nanotubes, bro."
3. **Level 3**: "I've surgically replaced my hands with actual diamonds. The hospital bills are catastrophic but I'm STILL HOLDING."
```
