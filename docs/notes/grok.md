# grok.md — Grok AI Assistant Guide for the_jokesters

> Read this first.

## Project Overview
**the_jokesters** is a comedy improv show featuring LLM-powered 3D avatars with WebGPU TTS. It’s a playful fusion of AI, performance, and real-time 3D graphics.

- **Live Demo**: https://test.1ink.us/the-jokesters/index.html
- **Core Fun**: Watch AI characters tell jokes, react, and perform with natural speech and expressive 3D animation.

## Technology Stack
- TypeScript + Vite
- LLM integration (likely via API)
- WebGPU for 3D avatars and rendering
- ONNX Runtime Web or similar for TTS
- 3D avatar models and animation

## Grok Guidelines
- **Character & Personality**: The magic is in the avatars’ personality, timing, and comedic delivery.
- **Real-time Performance**: Keep lip-sync, expressions, and reactions smooth and believable.
- **LLM Integration**: Focus on good prompt engineering, context management, and low-latency responses.
- **Visual Polish**: High-quality 3D models, lighting, and animations make the experience much more engaging.
- **Interactivity**: Allow users to prompt new jokes, change characters, or influence the show.

## Common Tasks
- Improve avatar animation and lip-sync
- Enhance TTS quality and expressiveness
- Add new characters or scenes
- Optimize LLM calls and reduce latency
- Add audience interaction features
