# sidecar/ — out-of-app tooling

Nothing in here is part of the browser app. None of it is imported by `src/`,
built by Vite, type-checked by `tsc -b`, linted, or run by CI/`package.json`.
It is kept for reference and occasional manual use.

| Path | What it is |
|------|-----------|
| `hf_spaces/` | Hugging Face Space apps (comedy-tester, bark-small-webgpu, kimi-vl-converter). `comedy-tester/prompts.json` is generated by `npx tsx scripts/export-comedy-prompts.ts`. |
| `utils/` | Colab notebooks and the kimi-audio server experiment (model conversion). Not to be confused with `src/utils/`. |
| `experiments/` | Research notes (Bark on WebGPU). |
| `backend/` | `llama_proxy.py`, a standalone FastAPI router sketch with no app around it. |

If something here becomes part of the product, move it into `src/` (or
`scripts/` for build tooling) and give it a test.
